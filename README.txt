Cara mencoba:
1. Ekstrak ZIP.
2. Buka folder cetakin-website menggunakan Visual Studio Code.
3. Klik kanan index.html > Open with Live Server.
   Alternatif: buka index.html langsung lewat browser.

Untuk upload ke GitHub Pages:
- Upload isi folder (index.html, style.css, script.js, assets/) ke root repository.
- Buka Settings > Pages > Deploy from a branch > main > /root.
